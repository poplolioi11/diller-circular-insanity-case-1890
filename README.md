# 循環性精神病病例報告（1890） / Circular Insanity. A Contribution to the Study of the Affection.—Report of a Case — Transcription Dataset

Theodore Diller 的 1890 年病例報告追蹤一名歷史患者三次入院的情況，以病房觀察記錄不同時段的情緒、活動及轉歸。第 180 頁有時序表，另保留文中的兩個比較病例。

Theodore Diller’s 1890 case report follows a patient across three admissions, describing ward transfers, mood, activity, and discharge. It includes a chronology on printed page 180 and two shorter comparisons, using the period term circular insanity.

## Source and scope

University of Toronto Libraries, Gerstein Science Information Centre, Alienist and Neurologist vol. 11 / alienistneurolog11stlouoft, Source frames 1–9. ## Files

- `transcription.txt` retains line and frame markers. Tabs mark table cells. 
- `transcription.json` identifies each frame and text or table unit. A null printed page means no printed page number was recorded. The source links identify the corresponding scan.
- `transcription.tei.xml` maps the same frame text and table cells into TEI P5.
- `review-notes.md` lists review coverage and reading decisions.
## Transcription and review

AI-assisted reading used fixed source scans. Published text preserves printed spellings and historical terminology. Spacing may be normalized. A square (□) indicates an unresolved character. See the notes for editorial omissions and uncertain readings.

Version 0.2.1. This dataset has no measured error rate or expert proofreading.
